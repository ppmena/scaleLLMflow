# Examples

The repository examples are self-contained scripts and fixtures: `01_simple_example` is a minimal workflow; `02_mqs_free` uses MQS without references; `03_mqs_reference` compares reviewed fixtures; `04_pedro_free` exercises PEDro; `05_model_reference_comparison` compares providers; `06_claude_free` uses Claude; `07_training_mqs_1` trains prompts locally; and `08_rob2_chatgpt56_luna` and `09_rob2_gemini` demonstrate RoB 2.

Run provider examples only after configuring credentials and checking the selected model. Bundled articles and `ideal_results.csv` files are demonstrations, not a substitute for study-specific validation.
